# miss-read

> **未读、误读、重读。**  
> A source is a beginning, not a conclusion.

一本书还没读完，一种观点还没想明白，都可以先在这里留下线索。

这里不是“读完了多少本书”的战绩墙，也不代替阅读。它是一个可以逐步纠错、标明出处、追踪问题的独立知识库。

## 记录规则

每一条笔记尽量区分四个层次：

1. **可查来源**：书名、作者、版次、页码、DOI、官网链接等。
2. **作者原意**：作者究竟主张什么？仅看目录与简介时，明确写“尚未核对正文”。
3. **讨论与争议**：支持证据、替代解释与反对意见是什么？
4. **自己的判断**：只有充分理解后才写；暂时没有结论也可以。

### 标记

- `📎 书目信息` — 信息已找到，内容尚未阅读。
- `🗂️ 公开资料导读` — 根据简介、目录或其他公开资料编写，**不冒充读书心得**。
- `📖 部分阅读` — 读过具体章节，记录章节/页码。
- `✅ 全文阅读` — 已经通读，仍可能需要核实。
- `❓待核实` — 来源、事实、作者论证或反例仍需追查。
- `✍️ 个人判断` — 形成的判断与理由，可在后来修订。

> **资料的丰富，不代表认知已经发生。** 保存一个问题，正是为了将来有能力重新回答它。
